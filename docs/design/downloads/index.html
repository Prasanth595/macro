Downloading files

JD Design proposal · Desktop & mobile

A clear way to get a file from Macro onto your device.

“Also it would be nice to make the download button less buried in drive.”Austin · 15 October feedback

1. Keep Download beside the file

A video in a channel gets a visible Download action below the preview. The expanded viewer keeps the same action.

2. Put it in the Drive header

Download sits beside Share when a file is open. Keep the existing menu option as another way in.

3. Make the result clear

Name the file and show its type and size when known.
Use “Download started” for a browser handoff.
On phones, offer “Save or share…” with separate destinations.

Try the Download action in the channel. Use the controls below to compare Drive, mobile, and failure states. Transfers and sample conversations are simulated.
