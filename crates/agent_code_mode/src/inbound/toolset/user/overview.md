Use the real Macro SDK, prebundled for Deno. Write an ES module exporting async main({macro}); optionally import {Macro} from "@macro-inc/sdk" or Handlebars from "handlebars". The provided macro is already authenticated as the signed-in user; main also receives token and hosts for explicit construction. Never expose the token.
Entity handles are lazy: byId returns a handle, a field accessor may fetch data, search/recent/inbox return async iterators. Await methods and use for await for iterators. Return plain JSON as {data}. No runtime documentation helper, TypeScript compilation or package fetching.
APIs enforce normal user permissions and metering. Execution has a 30-second deadline; use small parallel batches and early stopping when sufficient. Nothing is saved between executions.
