01 / The user promise

A file in Macro.
A clear way to keep it.

Make downloading visible, name what people will get, and explain what happens next — in a channel, in Drive, and on a phone.

What the feedback tells us

A channel video had no obvious way to download. Drive users needed a teammate to show them how.

Read the source thread ↗
01 — Find it

Put the verb by the file.

A labeled Download action stays visible. No hover or overflow menu required.

02 — Understand it

Name what leaves Macro.

Show the filename, type, and known size. Keep file sharing distinct from sharing a link.

03 — Follow through

Explain where it goes.

Show progress, an honest handoff message, and a way to recover when saving fails.
